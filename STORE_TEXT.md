## Description

LiteTerrain is a lightweight terrain editor addon with English and Arabic interfaces and touch-friendly controls.

Sculpt and smooth terrain, paint four texture layers, and generate maps with a 3D preview before applying changes. Paint grass using crossed texture cards or Node3D scenes, or scatter a chosen number of plants. Terrain edits, foliage painting and generation support undo and redo.

Features include 64, 128 and 256 meter maps, runtime terrain mesh LOD, texture mipmaps, clustered grass density LOD, and full-map or player-following collision. Scene vegetation supports distance culling and existing imported mesh LOD. The addon does not require native extensions.

Tested with Godot 4.7.1 on Windows using the Compatibility renderer. Designed with mobile editing in mind, but not yet tested on physical Android hardware. Erosion uses lightweight diffusion; the preview sea is not added to the scene.

Install addons/lite_terrain, enable LiteTerrain in Project Settings > Plugins, and select a LiteTerrain node. Read the included bilingual manual for controls and setup.
